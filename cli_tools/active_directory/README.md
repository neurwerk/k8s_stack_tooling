Read-only AD group-assignment report: `uv run --project /path/to/tooling/cli_tools/active_directory --frozen active-directory report --context <context>`; reuses the existing Kubernetes tunnel, live Helm inputs, bind Secret and Keycloak Pod (JDK 21 with JShell), with credentials sent only in memory over exec stdin.
Use `--unassigned-only`, `--base-dn <employee-OU>`, `--filter <LDAP-filter>`, or `--json`; defaults cover enabled AD person accounts, which can include service accounts, and at most 10000 results (`--limit`); exit 2 means missing groups, truncated/referral results or another incomplete check, and the report shows visible memberships rather than login, email-invitation or effective-access history.
